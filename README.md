# Independent Clinical AI Content Review

A personal, independent educational website by Dr. T. Jeevaraj. No consultancy, patient data collection, visitor authentication, commercial clinical review services or institutional endorsement.

## Deployment

Upload the **contents** of this folder (not the enclosing folder) to the root of `jeevantjr/clinical-ai-review` on GitHub. Enable GitHub Pages: Settings → Pages → Deploy from a branch → main / root.

The existing `index.html` and `assets/styles.css`, `assets/site.js`, and `assets/favicon.svg` will be replaced. Keep a backup or use a reviewable branch before publishing.

This project uses static HTML/CSS/JavaScript and no build system. `python -m http.server 8000` serves it locally.

## Notes

- The Reviews page accurately says no completed reviews are published. Add real articles only after source verification.
- The methodology is a proposed editorial rubric, not a validated tool.
- Book image and reviewer portrait are provided by the site owner.
- The site does not include tracking scripts or contact forms.
- Check final identity, study details and image permissions before publication.
- Canonical and sitemap URLs target `https://jeevantjr.github.io/clinical-ai-review/`. Update all URLs if moving to a custom domain.
- No open-source license is granted by this package.
